================================================================================
DECISIONS
================================================================================

D1  No build step. Plain HTML, CSS and ES modules.
    Reason: Chrome loads extension files directly. A bundler costs hours of
    configuration and produces no user-visible value in a 24-hour window.
    Settled. Do not reopen.

D2  Side panel, not popup.
    Reason: popups close on click-away, which destroys the follow-up
    conversation state. Settled.

D3  Model provider is Google Gemini Flash, behind an adapter in
    lib/providers/. Reason: free tier, low latency, native image input for
    the Grafana test page, strong Indic script handling for the Telugu test
    page. Swapping providers means adding one adapter file.

D4  Model API calls originate in sidepanel.js, not background.js.
    Reason: the side panel is a full extension page with host permissions and
    can stream a fetch response directly into the DOM. Routing through the
    service worker requires a long-lived port and risks eviction mid-stream.

D5  Permissions are limited to activeTab, scripting, storage, sidePanel, tabs,
    plus a single host permission for the model API origin. <all_urls> is
    forbidden. Reason: graded requirement, and activeTab already satisfies the
    deliberate-user-action rule.
